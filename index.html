          How to get your keys

          Claude API key (runs the hosts)

          1. Go to platform.claude.com and sign in.
          2. Open Settings, then Billing. Add a payment method and a small amount of credit.
          3. Open Settings, then Limits. Set a monthly limit, like $5. The station can never spend more than that.
          4. Open Settings, then API Keys. Tap Create Key, name it Lune FM, and copy it. It starts with sk-ant- and only shows once.
          5. Paste it in the Claude API key box below.

          YouTube API key (finds the songs, free)

          1. Go to console.cloud.google.com and create a project called Lune FM.
          2. Open APIs and Services, then Library. Search for YouTube Data API v3 and tap Enable.
          3. Open APIs and Services, then Credentials. Tap Create credentials, then API key, and copy it.
          4. Paste it in the YouTube API key box below.

          Natural voices (optional, same Google project)

          1. In the same project, open APIs and Services, then Library. Search for Cloud Text-to-Speech API and tap Enable.
          2. Google asks you to turn on billing for this API, even on the free tier. Follow its steps. The first 1 million characters each month are free, which covers several hours of listening every day. After that it's $30 per million characters, so set a budget alert under Billing if you want a heads-up.
          3. If you limited your key to certain APIs, edit the key and add Cloud Text-to-Speech API to the list. Then your YouTube key works for both, and you can leave the voice key box empty.

          Locking your Google key to your site (do this last)

          1. Once everything works, edit the key. Under Application restrictions, pick Websites and add https://your-name.github.io/*. Save.

          Then tap Test keys. Your keys stay in this browser only. They are not in the page's code, so your GitHub page never shows them.

          Keys
          Your other devices

          Make a link that carries your keys, hosts, shows and taste to another phone or computer. It's locked with a PIN you pick. Anyone with both the link and the PIN gets your keys, so only send it to yourself.

          Your station
          Shows

          The station follows this schedule by the clock on your device. Each show runs until the next one starts.

          Hosts

          Each host is its own Claude agent with its own personality, voice and notebook. They share the mic, react to each other, and react to what you love or skip.

          Once a week, each host looks at their picks and how you reacted, and updates what they're into lately. Their personality stays the same. A few cents a week.

          Your taste

          When you tap Love it or More like this on two different songs by someone who isn't on your list, they get added.

          Keeps one artist from taking over. The count rolls, so once an older play is past the window, that artist can come back. Never two in a row either way.

          YouTube doesn't label clean and explicit versions, so the station goes by how uploads are named and steers away from ones marked clean, edited or radio edit. If a censored one still gets through, tap Wrong version under the song, then Censored. It switches versions and remembers.

          Daily briefing

          The song picker only knows music up to a certain date. With this on, the station searches the web each day for new songs and albums from your artists and artists like them, and works them into the shows. About three web searches a day, a few cents.

          It airs early in the first show you tune into each day, read by whoever has the news desk.

          Behind the scenes
          If something goes wrong, tap this and paste it to Claude. It shows what the AI sent back. It never includes your keys.
          Your data

          Shows, loved songs and settings live in this browser. Export a backup now and then. Backups never include your keys.
