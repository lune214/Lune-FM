      How to get your two keys

      Claude API key (runs the host)

      1. Go to platform.claude.com and sign in or make an account.
      2. Open Settings, then Billing. Add a payment method and a small amount of credit.
      3. Open Settings, then Limits. Set a monthly limit, like $5. The station can never spend more than that.
      4. Open Settings, then API Keys. Tap Create Key, name it Lune FM, and copy it. It starts with sk-ant- and only shows once.
      5. Paste it in the Claude API key box below.

      YouTube API key (finds the songs, free)

      1. Go to console.cloud.google.com, sign in with your Google account, and create a project called Lune FM.
      2. Open APIs and Services, then Library. Search for YouTube Data API v3 and tap Enable.
      3. Open APIs and Services, then Credentials. Tap Create credentials, then API key, and copy it.
      4. Edit the key. Under Application restrictions, pick Websites and add https://your-name.github.io/*. Under API restrictions, pick YouTube Data API v3. Save.
      5. Paste it in the YouTube API key box below.

      Then tap Test keys. Your keys stay in this browser only. They are not in the page's code, so your GitHub page never shows them.
